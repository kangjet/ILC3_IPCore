# CoPBit Q4 – Kuramoto Cluster Demo v0.1 메모

## Q4-1. 실험 목적

- Q3에서 정의한 4비트/16포인트 CoPBit 위상 맵핑을 그대로 사용.
- 포인트 4개씩을 하나의 클러스터(총 4개 클러스터)로 묶고,
- Kuramoto intra-cluster coupling(`k_intra=1.5`) + 위상 노이즈(σ≈3–4°)를 인가했을 때
  - 각 클러스터가 얼마나 잘 동기화(synchronization) 상태를 유지하는지
  - 클러스터 평균 위상이 시간에 따라 어떻게 움직이는지
  를 관찰하는 것이 목적.

---

## Q4-2. 설정 요약

- 포인트 수: N = 16 (4bit, CoPBit Q1 맵핑 그대로)
- 클러스터: 4개 (각각 4포인트)
- 동역학:
  - Kuramoto 식:  
    \[
      \dot{\theta_i} = \omega_i
        + \frac{k_{\text{intra}}}{N_c} \sum_{j \in \text{same cluster}}
          \sin(\theta_j - \theta_i)
        + \eta_i(t)
    \]
  - `k_intra = 1.5` (클러스터 내부 결합 강도)
  - `η_i(t)` : 가우시안 위상 노이즈 (deg 단위 σ)

- 실험 1:
  - `n_steps=200`, `dt=0.05`
  - `noise_std_deg = 3.0`
  - `init_jitter_deg = 10.0`
- 실험 2:
  - `n_steps=400`, `dt=0.05`
  - `noise_std_deg = 4.0`
  - `init_jitter_deg = 20.0`

## Q4-3. 실험 1 결과 (σ=3°, n_steps=200)

- 초기 클러스터 평균 위상 (deg):
  - 약 `[ 34.5, 126.9, 216.7, 301.6 ]`
- 최종 클러스터 평균 위상 (deg):
  - `[ 32.8, 121.0, 218.8, 306.0 ]`
- 최종 클러스터별 order parameter \(R_c\):
  - `[0.9995, 0.9996, 0.9999, 0.9998]`

해석:

- 각 클러스터 내부 위상은 거의 완전히 잠긴 상태 (`R_c ≈ 1`).
- 평균 위상은 초기값에서 몇 도 수준만 드리프트.
- Polar 플롯에서도 4개 포인트가 매우 좁은 위상 구름으로 모여 있고,
  클러스터 평균(X 마크)이 그 중심을 잘 대표함.

→ σ=3° 수준의 위상 노이즈에서는,
   Kuramoto 결합 덕분에 각 4포인트가 **사실상 하나의 집단 위상 비트 덩어리**로 동작함.

## Q4-4. 실험 2 결과 (σ=4°, n_steps=400, 초기 jitter 20°)

- 초기 클러스터 평균 위상 (deg):
  - 약 `[ 34.9, 130.1, 219.6, 299.4 ]`
- 최종 클러스터 평균 위상 (deg):
  - `[ 22.7, 130.0, 234.7, 291.5 ]`
- 최종 클러스터별 order parameter \(R_c\):
  - `[0.9995, 0.9991, 0.9998, 0.9997]`

해석:

- 노이즈와 초기 무작위 편차를 크게 줬음에도,
  각 클러스터는 여전히 `R_c ≈ 1` 상태로 강하게 동기화.
- 평균 위상 위치만 전체적으로 이동했을 뿐,
  클러스터 내부 포인트 간 상대 위상 구조는 거의 고정.

→ 강한 초기 jitter + 더 큰 σ에서도,
   “4포인트 묶음 = 하나의 견고한 Kuramoto 위상 클러스터”라는 구조가 유지됨.

## Q4-5. Q3 대비 의미

- Q3: 단일 포인트 기준 위상 AWGN + 최근접 디코더 → σ가 커지면 바로 BER 증가.
- Q4: 4포인트를 하나의 Kuramoto 클러스터로 묶어
  - 클러스터 평균 위상을 추적하고,
  - 각 심볼은 “클러스터 평균 + 상대 위상 오프셋”으로 보게 되면,
- 동일 σ 조건에서도 **위상 추정/복원이 훨씬 안정적일 가능성**을 보여줌.

→ CoPBit 1024-lane 구조에서,
   - lane 내 Kuramoto coupling으로 **집단 위상 비트**를 만들고,
   - 상위 계층에서 이 집단 위상을 이용한 암호/보안/PPU 연산으로 확장하는
   첫 단계 개념 검증으로 볼 수 있음.
