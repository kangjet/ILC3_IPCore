  - 4bit (또는 그 이상) 정보를 **3D 포인트(진폭 + 위상 + 보조축)**로 매핑하는 규칙 초안.

## 2. 설계 기본 가정 (초안)

### 2.1 차원 정의

- CoPBit 1-lane 심볼을 3차원 공간의 포인트로 표현:
  - 축 1: 진폭 (Amplitude) → 예: {-1, 0, +1} 또는 {A1, A2, A3}
  - 축 2: 위상 (Phase) → 예: 0, π/2, π, 3π/2 (4포인트) 또는 더 세분화된 포인트
  - 축 3: 보조축 (Aux) → 예:
    - Guard phase / 내부 상태 / parity 역할
    - 혹은 Kuramoto 커플링에서 “군집/그룹 ID” 역할

> v0.1 단계에서는 **수학적으로 가장 단순한 구조**부터 시도하고,  
> 나중에 Q2/Q3에서 Kuramoto/암호 적용에 맞게 수정 가능하다고 가정.

---

### 2.2 심볼 수 및 매핑 단위

- 1심볼당 표현 비트수(초안):
  - 기본 가정: **4bit/심볼** (16포인트)
- 후보:
  1. **Case A – 16포인트 고정**
     - 3D 공간 상에 16개 포인트 정의
     - 각 포인트 ↔ 4bit 정수(0~15) 1:1 대응
  2. **Case B – 3레벨 진폭 + 4위상 조합**
     - 진폭: {-1, 0, +1} (3레벨)
     - 위상: 4단계 (예: 0, π/2, π, 3π/2)
     - 전체 12포인트 + 나머지 4포인트는 Guard/Control용으로 예약

Q1에서는 **Case A/B 중 하나를 v0.1 기준안으로 선택**하고,  
다른 하나는 “대체안/보류안”으로 메모해 두는 방식으로 진행.

## 3. 좌표계 및 수학적 표현 (초안 틀)

### 3.1 극좌표/구면좌표 기반 표현

- 각 심볼을 (r, θ, φ) 또는 (x, y, z)로 표현:
  - r: 진폭(반지름)
  - θ: 위상(주 위상 축, CoPBit의 핵심)
  - φ: 보조각 (guard / aux 상태)

예시 형태(채워 넣을 자리):

- r ∈ {r₁, r₂, r₃}  (3레벨 진폭)
- θ ∈ {0, π/2, π, 3π/2} (4위상)
- φ ∈ {0, φ_g}   (예: guard 상태 on/off)

> 실제 수치는 Q1 진행 중에 Python으로 시각화/검토하면서 결정.

### 3.2 심볼 매핑 테이블 (v0.1)

## 4. Kuramoto 커플링을 고려한 제약사항 메모

CoPBit은 단순한 변조 포인트가 아니라,  
**위상 커플링(동기화/비동기화) 연산까지 포함하는 연산 primitive**가 목표라서,  
Q1에서 다음을 염두에 두고 설계해야 한다:

1. **위상 차이(Δθ)가 중요한 변수**
   - Kuramoto 모델의 기본 항: `sin(θ_j - θ_i)`
   - → 포인트 간 위상 차이가 **연산 에너지/속도/수렴성**에 직접 영향

2. **군집(Cluster) 구조**
   - 16포인트를 단순히 균등 분포만 하지 말고,
   - “동일 클러스터/다른 클러스터” 구분에 유리한 배치를 고려
   - 예: 4개 클러스터 × 4포인트, 각 클러스터별 위상/진폭 패턴 지정

3. **노이즈·암호 적용 여지**
   - 일부 포인트는 “암호용, 보호용, 패턴 교란용”으로 예약해 둘 여지도 있음.
   - ex) φ 축을 이용해서 “관찰자에게는 노이즈처럼 보이지만, 내부적으로는 의미 있는 상태” 구현.

이 항목들은 수식/좌표를 정할 때 우측에 “Kuramoto/암호 관점 메모”로 같이 적어 두는 용도로 사용.

### 2.2 심볼 수 및 매핑 단위 (v0.1 확정)

- 1심볼당 표현 비트수:
  - **4bit/심볼** → **16포인트** 고정 (Case A 기준안 채택)
- 설계 방향:
  - **3D 표현이지만, v0.1에서는 에너지/회로 단순화를 위해 반지름 r은 고정**
  - 주된 정보는 **위상(θ) + 보조축(φ, 클러스터)** 에서 나온다고 가정

#### 2.2.1 3D 좌표 정의 (v0.1)

- r: 고정 반지름  
  - 예: r = 1 (정규화된 에너지 기준)
- θ: 16분할 위상 (주 위상 축)
  - k = 0..15 에 대해  
    \[
      \theta_k = \frac{2\pi}{16} \cdot k
    \]
- φ: 클러스터(군집) 보조각
  - 4개 클러스터 × 4포인트 구조:
    - 클러스터 인덱스: \( c = \lfloor k / 4 \rfloor \in \{0,1,2,3\} \)
    - 클러스터별 보조각:
      \[
        \phi_c = c \cdot \phi_{\text{step}}
      \]
    - 여기서 \(\phi_{\text{step}}\)은 작은 고정 각도 (예: \(\phi_{\text{step}} = \pi/16\) 정도, Q2에서 튜닝)

→ 결국 각 심볼은  
\[
  S_k = (r, \theta_k, \phi_c), \quad k = 0..15,\ c = \lfloor k/4 \rfloor
\]

#### 2.2.2 비트 매핑 규칙 (v0.1)

- 4bit 패턴을 **상위 2bit = 클러스터 / 하위 2bit = 클러스터 내 위치**로 사용:

- 비트 정의:
  - \(b_3 b_2 b_1 b_0\) (MSB → LSB)
  - 클러스터 인덱스 \(c = (b_3 b_2)_2 \in \{0,1,2,3\}\)
  - 클러스터 내 인덱스 \(i = (b_1 b_0)_2 \in \{0,1,2,3\}\)
  - 전체 심볼 인덱스:
    \[
      k = 4c + i
    \]

- 그에 따른 파라미터:
  - \(\theta_{c,i} = \frac{2\pi}{16} \cdot (4c + i)\)
  - \(\phi_c = c \cdot \phi_{\text{step}}\)
  - r = 1 (고정)

이 구조의 의미:
- **하위 2bit만 바뀌면** 같은 클러스터 안에서 **θ만 조금 달라지는 “가까운 이동”**  
- **상위 2bit가 바뀌면** φ축이 달라져서 **다른 클러스터로 점프**  
→ Kuramoto 관점에서는 “같은 클러스터 = 위상 동기화 그룹”,  
   FEC/BER 관점에서는 “근접 심볼 = Hamming distance 1~2에 해당”처럼 활용 가능.

 ## 7. Q1 v0.1 요약

- 4bit/심볼 → 16포인트 고정
- 좌표:
  - r = 1 (정규화)
  - θ_k = 2π·k/16,  k=0..15
  - c = ⌊k/4⌋,  φ_c = c·φ_step,  φ_step = π/16 (v0.1 기준값)
- 비트 매핑:
  - (b3 b2) = 클러스터 인덱스 c
  - (b1 b0) = 클러스터 내부 인덱스 i
  - k = 4c + i
- 의미:
  - 동일 클러스터: φ 동일, θ만 조금 다른 “근접 위상 그룹”
  - 다른 클러스터: φ가 다름 → Kuramoto/암호 관점에서 다른 그룹으로 해석 가능

> Q2에서 φ_step, 클러스터 구조, 거리 매트릭(에너지/BER 관점)을 다시 튜닝할 수 있다.
