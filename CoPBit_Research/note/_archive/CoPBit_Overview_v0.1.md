작성일: 2025-12-02

## 1. CoPBit 프로젝트 목표

- ILC3/ILC4에서 확장된 **위상 기반 3D 병렬 연산 구조** 정의
- 1024 lane 이상 병렬 구조를 활용한
  - 저전력 고속 연산 (PPU 개념)
  - 암호·보안·무결성 검사용 연산 primitive
- 장기적으로는
  - 1단계: 암호/보안용 CoPBit 연산 primitive
  - 2단계: 온디바이스 PPU
  - 3단계: GPU/NPU/TPU 대체 후보 아키텍처

## 2. 1st Step 범위 (v0.1)

- **1-lane CoPBit 3D 위상/진폭 모델 정의**
  - 16-포인트(또는 15-포인트) 3D 위성 구조
  - Kuramoto-style 위상 커플링 요소 포함
- **기본 연산 primitive 정의**
  - 진폭 레벨: {-1, 0, +1} 또는 유사 3레벨 구조
  - 위상·진폭 조합을 이용한 연산 규칙 초안
- **암호/보안 응용 1차 스케치**
  - SNR을 의도적으로 흔드는 보호 레이어 개념
  - 1024 lane 이상 병렬 구조에서의 키/패턴 표현 아이디어 메모

## 3. 디렉터리 구조

- `python/`  : Python 시뮬레이션, Kuramoto/위상 연산 실험
- `rtl/`     : CoPBit RTL/테스트벤치 (후속 단계에서 채움)
- `docs/`    : CoPBit 개념 문서, 특허/논문 초안, 투자 브리프 등
- `note/`    : 일자별 작업 로그, Q1~Qn 정리
- `data/`    : npz/log/json 등 실험 결과 데이터

## 4. 초기 Q-시리즈(초안)

- **Q1**: 1-lane CoPBit 위상/진폭 3D 위성 정의  
- **Q2**: Kuramoto 커플링을 통한 위상 정렬/보정 실험  
- **Q3**: 1024 lane 배열에서의 병렬 연산 primitive 초안  
- **Q4**: 암호/보안용 “SNR 교란 레이어” 개념 검토  
- **Q5**: ILC3/ILC4 대비 CoPBit 차별 포인트 정리 (특허·사업 관점)

비트-위상 매핑정의
### CoPBit Q3-1: 4bit 비트 매핑 표 (v0.1)

| k  | bits | c (상위 2bit) | p (하위 2bit) | θ = theta[deg] |
|----|------|---------------|---------------|----------------|
|  0 | 0000 | 0             | 0             |   0.00         |
|  1 | 0001 | 0             | 1             |  22.50         |
|  2 | 0010 | 0             | 2             |  45.00         |
|  3 | 0011 | 0             | 3             |  67.50         |
|  4 | 0100 | 1             | 0             |  90.00         |
|  5 | 0101 | 1             | 1             | 112.50         |
|  6 | 0110 | 1             | 2             | 135.00         |
|  7 | 0111 | 1             | 3             | 157.50         |
|  8 | 1000 | 2             | 0             | 180.00         |
|  9 | 1001 | 2             | 1             | 202.50         |
| 10 | 1010 | 2             | 2             | 225.00         |
| 11 | 1011 | 2             | 3             | 247.50         |
| 12 | 1100 | 3             | 0             | 270.00         |
| 13 | 1101 | 3             | 1             | 292.50         |
| 14 | 1110 | 3             | 2             | 315.00         |
| 15 | 1111 | 3             | 3             | 337.50         |

- 상위 2bit(b3,b2) = c = 0,1,2,3  → 4개 클러스터
- 하위 2bit(b1,b0) = p = 0,1,2,3  → 각 클러스터 내부의 4개 포인트
- `θ = 360° * k / 16`
