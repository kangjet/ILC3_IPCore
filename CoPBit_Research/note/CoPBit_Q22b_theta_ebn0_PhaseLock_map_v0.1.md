# CoPBit Q22b – M8 mid-ISI + FFE(LS) + p_ref PLL  
### θ_std_deg–Eb/N0 PhaseLock 맵 (Q22a 확장)

---

## 1. 실험 목적

- Q22a에서 얻은 **단일 조건(θ_std = 0, 1, 3, 5° / Eb/N0 = 12, 14, 16, 18 dB)** 결과를
  더 촘촘한 θ_std 격자에서 확장한 실험.
- 목표:
  - **mid-ISI + FFE(LS)** 환경에서  
    CoPBit M8 + 1-lane p_ref PLL의 **PhaseLock 허용 범위(θ_std_max)** 를  
    **Eb/N0마다 수치적으로 맵핑**.
  - 특히 **BER_DD+pRef 기준으로 BER ≈ 10⁻³, 10⁻² 수준에서의  
    (Eb/N0, θ_std_deg) 조합**을 데이터로 남기는 것.

---

## 2. 시스템 / 시뮬레이션 설정

### 2.1 변조 및 채널

- **변조**
  - 8-PSK (M8), 3bit/sym, 그레이 코딩
- **채널 (mid-ISI)**
  - Channel-b 5-tap, 심볼레이트 채널
  - 정규화된 채널:  
    \[
      h_\text{midISI} = [0.05,\; 0.2,\; 0.5,\; 0.2,\; 0.05] + 0j
    \]

### 2.2 등화기 (FFE, LS 고정 계수)

- 공통 FFE (M8 기준, 복소 tap)
- tap 길이: **L = 11**
- 트레이닝 비율: **train_frac = 0.5**
- 방식: **LS(Least Squares)로 계수 추정 후, 데이터 구간에서는 계수 고정**
  - 즉, “FFE + 고정 계수 채널 보상” 구조
  - 이후 위상 노이즈와 PLL 실험은 **FFE가 만든 등가 채널** 위에서 진행

### 2.3 위상 노이즈 + PLL 구조

- **레이아웃**
  - Lane0: **p_ref lane** (고정된 8-PSK index)
  - Lane1: **data lane** (3bit/sym 랜덤 데이터)
- **공통 위상 노이즈**
  - Δφ ~ N(0, σ²), σ = θ_std_deg[deg] → rad 변환 후 누적 (Wiener process)
  - 모든 레인이 **동일한 공통 phase** 공유 (common phase-noise)
- **PLL 모드**
  - No PLL:
    - data lane에 FFE + slicer만 적용 (위상 추적 없음)
  - Data-DD only:
    - data lane 오류만 이용해서 공통 φ 업데이트 (1-lane DD-PLL 근사)
  - Data + p_ref:
    - p_ref lane 오류(err_ref) + data lane 오류(err_data)를 섞어서 φ 업데이트  
      - total_err = (1-α)·err_ref + α·err_data  
      - **alpha_ref = 0.3** (p_ref 쪽에 더 큰 가중치)
- **관심 지표**
  - **BER_DD+pRef** (p_ref 기반 PLL이 실제로 만들어 내는 최종 성능)

### 2.4 스윕 파라미터

- n_sym: **200k**
- Eb/N0_dB: **12, 14, 16, 18 dB**
- θ_std_deg: **0.0, 0.5, 0.8, 1.0, 1.2, 1.5, 2.0 deg**
- seed: 1

5. 핵심 관찰 포인트

5.1 θ_std_deg 증가에 따른 패턴
	•	모든 Eb/N0에서 θ_std_deg가 커질수록 BER_DD+pRef는 단조 증가.
	•	θ_std = 0°일 때는 mid-ISI + FFE(LS) 자체의 잔여 ISI + AWGN만 남아 매우 낮은 BER 형성.
	•	θ_std를 2°까지 올리면:
	•	16 dB에서도 BER ≈ 1e-2 수준까지 악화
	•	18 dB에서는 여전히 5e-3 수준으로 “버티는” 플로어가 존재.

5.2 p_ref PLL의 역할
	•	No PLL / Data-only PLL:
	•	θ_std가 커지면 금방 BER ≈ 0.5 근처로 붕괴.
	•	p_ref PLL (Data+p_ref):
	•	같은 환경에서도 BER를 10⁻²~10⁻³로 “붙잡고 있는” 평형점 형성.
	•	특히 Eb/N0 ≥ 16 dB + θ_std ≤ 1°에서는
메모리/버스 용도로 충분한 신뢰성(10⁻³ 수준) 확보.

→ 정리하면, “1개의 p_ref lane + Kuramoto식 공통 PLL”만으로도
mid-ISI + FFE(LS) 환경에서 전체 타일의 위상을 잡는 것이 가능하다는 정량적 근거.

⸻

6. 설계 관점 요약 (PhaseLock_std 맵)

6.1 PPU(연산 코어) 근거리 모드
	•	목표: Pre-FEC BER ≲ 10⁻³
	•	설계 포인트(예시):
	•	Eb/N0 ≳ 16 dB
	•	θ_std (공통 위상 표준편차) ≲ 0.5–0.7°
	•	이 조건이면:
	•	mid-ISI + FFE + 공통 위상 노이즈 환경에서도
	•	1 p_ref lane 기반 PLL만으로 PhaseLock_std 조건 충족

6.2 메모리 / 데이터 버스 모드
	•	목표: Pre-FEC BER ≲ 10⁻² (강력한 FEC 전제)
	•	설계 포인트(예시):
	•	Eb/N0 ≳ 14–16 dB
	•	θ_std ≲ 1.5–2°
	•	이 영역에서는:
	•	No PLL / Data-only PLL은 거의 항상 BER ≈ 0.5로 붕괴
	•	p_ref PLL 덕분에 “플로어”를 10⁻²~10⁻³로 내릴 수 있음
