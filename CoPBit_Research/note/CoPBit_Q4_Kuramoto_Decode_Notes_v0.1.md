# CoPBit Q4 – Kuramoto-aided 4bit 위상 디코딩 노트 v0.1

## 1. 목표

- Q3에서 얻은 **순수 위상 + 최근접 디코더 베이스라인**에,
  **Kuramoto 위상 동기화(집단 위상 정렬)** 를 추가했을 때:
  - 같은 phase noise σ에서 **Bit BER가 얼마나 개선되는지** 계량화한다.
- 최종 목표:
  - “Kuramoto-aided CoPBit 위상 스킴”이  
    단순 위상 디코더 대비 **허용 가능한 위상 노이즈 마진**을 얼마나 확장하는지
    (예: σ=5°에서 BER을 1e-2 → 1e-3대 이하로 낮추는지) 보여주는 것.

## 2. 기본 아이디어 (모델 스케치)

- 16포인트 CoPBit 위상 스킴:
  - k = 0..15 → θ_k = 2π·k/16
  - (c, p) (2bit + 2bit) ↔ 4bit 코드 B (0..15)
- 채널:
  - θ_tx[n] = θ_table[k_tx[n]]
  - θ_rx[n] = wrap(θ_tx[n] + N(0, σ_deg))
- Kuramoto 보조 계층:
  - 동일 심볼 스트림에 대해,  
    “근처에 있는 위상들끼리” 서로 끌어당기는 Kuramoto 형태의 보정 term 추가
  - 예시 개념:
    - φ[n+1] = φ[n] + α·wrap(θ_rx[n] − φ[n])  
      (+ 이웃 샘플/클러스터들의 평균을 이용한 coupling term)
  - 또는 “4개 클러스터 중심 위상”을 Kuramoto 식으로 업데이트해서,
    디코딩 시 **이동된 군집 중심**을 기준으로 최근접 디코딩.

## 3. 실험 플랜 (Q4 단계)

- Q4-1: 단일 클러스터 Kuramoto demo
  - 단일 CoPBit 클러스터(예: c=0)만 뽑아서,
  - 위상 노이즈 + Kuramoto 업데이트로
    군집 평균이 얼마나 안정적으로 유지되는지 시뮬레이션.

- Q4-2: 4클러스터 Kuramoto + 디코딩
  - 4개 클러스터(c=0..3)에 대해,
  - 각 클러스터 중심 위상 φ_c를 Kuramoto-like 업데이트로 추적.
  - 디코딩 시:
    - 이상적인 θ_k 대신,
    - 동적으로 추정된 φ_c와 p 인덱스를 조합한 “보정된 레퍼런스 위상” 사용.
  - 결과:
    - Q3와 동일한 σ 리스트(예: 3,4,5,6,8deg)에 대해
    - Bit BER(표)를 다시 찍고, Q3 베이스라인과 비교.

- Q4-3: 정리
  - “Kuramoto 없는 경우 vs 있는 경우” σ–BER 표/그래프 정리
  - CoPBit Phase BER Curve로 기술 문서/특허/논문에 넣을 수 있는 형태로 정리.

## 4. Q3 베이스라인과의 연결

- 이미 확보된 Q3 결과 (n_sym=50k 기준):

| phase_noise_std_deg (°) | Bit BER (No Kuramoto) |
|-------------------------|----------------------:|
| 3.0                     |            ≈ 1.5e-4   |
| 4.0                     |            ≈ 2.6e-3   |
| 5.0                     |            ≈ 1.17e-2  |
| 6.0                     |            ≈ 2.84e-2  |
| 8.0                     |            ≈ 7.44e-2  |

- Q4의 평가는,
  - 위 표의 각 σ에 대해 Kuramoto 보정 후 Bit BER을 다시 찍고
  - “같은 σ에서 BER 개선” 또는
  - “같은 BER(예: 1e-2)을 허용하는 σ 범위 확장” 관점에서 비교하는 것.
