# CoPBit Q23a – 1024-lane PPU 타일 (AWGN) + PhaseLock_std 검증 v0.1

## 1. 실험 목적

- Q16 / Q22에서 정의한 **PhaseLock_std 구조**가
- **PPU 1024-lane 타일 환경**에서도 그대로 확장 가능한지 확인.
- 채널은 메모리/버스 mid-ISI가 아니라, **PPU 연산에 대응되는 AWGN-only + 공통 위상 노이즈**로 설정.

목표 정리:

> θ_std ≤ O(1°) 구간에서,  
> 1024-lane PPU 타일의 BER이 PhaseLock 유무와 무관하게 충분히 낮게 유지되는지 확인.

---

## 2. 시뮬레이션 설정

- Modulation: M8 (8-PSK, 3bit/sym)
- Lanes: 1024 lanes
  - Lane 0: p_ref (고정 인덱스 0)
  - Lane 1..1023: data lanes (랜덤 0..7)
- 채널 모델:
  - AWGN-only + 심볼별 공통 위상 노이즈
  - φ_noise[n] ~ N(0, θ_std²) [rad]
- Eb/N0 리스트: 12, 14, 16 dB
- θ_std 리스트: 0.0°, 0.5°, 1.0°, 2.0°
- PhaseLock 모드:
  - noPLL    : 위상 추적 없음
  - DDonly   : data lanes만 이용한 위상 추적
  - DD+pRef  : p_ref + data 혼합 위상 추적 (alpha_ref = 0.3)
- 기타 파라미터:
  - n_sym = 50k
  - mu_phase = 0.05
  - seed = 1

## 3. 결과 요약

### 3.1. θ_std = 0.0° ~ 2.0° 에서의 BER

- 예시: θ_std = 0.0° / 0.5° / 1.0° / 2.0° (전체 결과 중 일부 발췌)

| θ_std (deg) | Eb/N0(dB) | BER_noPLL      | BER_DDonly     | BER_DD+pRef    |
|-------------|-----------|----------------|----------------|----------------|
| 0.0         | 12        | 1.93e-4        | 1.92e-4        | 1.97e-4        |
| 0.0         | 14        | 2e-6           | 2e-6           | 2e-6           |
| 0.0         | 16        | 0              | 0              | 0              |
| 0.5         | 12        | 2.01e-4        | 2.01e-4        | 2.04e-4        |
| 1.0         | 12        | 2.27e-4        | 2.29e-4        | 2.32e-4        |
| 2.0         | 12        | 3.77e-4        | 3.82e-4        | 3.87e-4        |
| 2.0         | 14        | 1.3e-5         | 1.3e-5         | 1.3e-5         |
| 2.0         | 16        | 0              | 0              | 0              |

특징:

- 모든 θ_std, 모든 모드에서 **BER_noPLL ≈ BER_DDonly ≈ BER_DD+pRef**.
- θ_std = 2° & 12 dB에서도 BER ≈ 3.8e-4 수준으로 충분히 낮음.
- 14 dB 이상에서는 사실상 에러가 관측되지 않을 정도의 수준.

## 4. 해석

1. **AWGN-only + 공통 위상 노이즈 환경**  
   - mid-ISI가 없고, 다만 전체 심볼이 약간씩 회전하는 구조.
   - 8-PSK 섹터 폭 = 45°.  
     θ_std = 2°는 섹터 폭의 ~4.4% 수준에 불과하여,
     Eb/N0 ≥ 12 dB 조건에서는 결정 경계를 넘는 케이스가 거의 발생하지 않음.

2. **PhaseLock_std의 존재감**  
   - 위상 drift가 크지 않고, 모든 lane이 동일한 φ_noise를 공유하므로  
     단일 global PLL이 보정할 에러가 거의 없음.
   - 실제 시뮬레이션에서도 noPLL / DDonly / DD+pRef 간 차이는
     소수점 4자리 이하의 미세한 수준.

3. **스케일 불변성 (2-lane → 64-lane → 1024-lane)**  
   - Q16/Q22에서 확인한 “θ_std ≤ 1° 구간에서 P_ref 기반 PhaseLock 구조가 안정적으로 동작”한다는 결론이
     **1024-lane PPU 타일까지 자연스럽게 확장됨**.
   - 특히 AWGN-only 환경에서는, 위상 노이즈 자체가 작기 때문에
     PhaseLock 유무와 무관하게 매우 낮은 BER을 유지.

---

## 5. 결론 (Q23a의 의미)

- 1024-lane CoPBit PPU 타일에 대해:

> **AWGN + θ_std ≤ 2° 조건에서는,  
>  P_ref 기반 PhaseLock_std 유무와 상관없이 연산에 필요한 BER을 충분히 만족한다.**

- 즉,
  - PPU 연산 측면에서 “위상 노이즈 때문에 전체 타일이 망가지는” 구간은
    현재 설정보다 훨씬 강한 노이즈 / 더 낮은 SNR에서나 문제 될 가능성이 크다.
  - 메모리/버스 채널(mid-ISI) 쪽에서 설계한 PhaseLock_std 구조를,
    PPU 연산 타일에 그대로 적용해도 **스케일/안정성 측면에서 문제가 없음**을 확인.
