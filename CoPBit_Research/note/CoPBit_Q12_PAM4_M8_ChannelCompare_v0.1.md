# CoPBit Q12 – PAM4 vs CoPBit-M8 Channel+AWGN (Eb/N0 basis) v0.1

- Date: 2025-12-03
- Script: `CoPBit_Research/python/copbit_q12_pam4_m8_channel_ebn0_v0.py`
- 목적:
  - ILC 계열에서 사용하던 5-tap 채널 a/b/c 위에서
  - **PAM4 (2bit/sym)** vs **CoPBit-M8 = 8-PSK (3bit/sym)** 을
  - **Eb/N0 기준(bit-fair)** 으로 BER 비교하는 *채널+AWGN 베이스라인* 확보.
  - 이 버전(v0.1)은 **EQ/FFE 없음**, 순수 채널+AWGN만 포함.

---

## 1. 실험 설정

```bash
python copbit_q12_pam4_m8_channel_ebn0_v0.py
	•	공통 파라미터
	•	n_sym = 100000
	•	Eb/N0_list(dB) = [0, 2, 4, 6, 8, 10, 12, 14, 16]
	•	channels = ['a', 'b', 'c']
	•	seed = 1
	•	변조
	•	PAM4
	•	레벨: [-3, -1, +1, +3] / sqrt(5) (Es ≈ 1 정규화)
	•	Gray mapping:
00→-3, 01→-1, 11→+1, 10→+3
	•	bits/sym = 2
	•	CoPBit-M8 (= 8-PSK)
	•	unit circle PSK: x[k] = exp(j*2πk/8),  k ∈ {0..7}
	•	비트 라벨: 단순 binary (Q1에서 정의한 CoPBit 특수 매핑은 아직 미반영)
	•	bits/sym = 3
	•	채널(5-tap ISI)
	•	a: [0.10, 0.40, 1.00, 0.40, 0.10] (가장 깨끗한 채널)
	•	b: [0.05, 0.50, 1.00, 0.50, 0.05] (가장 강한 ISI)
	•	c: [0.075, 0.45, 1.00, 0.45, 0.075] (중간 채널)
	•	노이즈
	•	Eb/N0 기준으로 bit-fair하게 Es/N0 계산:
	•	Es/N0 = Eb/N0 * k  (k = bits/sym)
	•	그에 해당하는 N0에서 complex AWGN 주입.

3. 해석 (현 단계 v0.1)
	1.	공통 양상 – ISI limit
	•	세 채널 모두 Eb/N0를 16 dB까지 올려도 BER이 0.18~0.27 근처에서 플래토.
	•	AWGN-only Q9/Q10에서 봤던 “SNR 올리면 급격히 떨어지는 M-PSK BER 곡선”과 달리,
여기서는 채널 + ISI가 완전히 메인 병목.
	•	즉, Q12 v0.1 결과는
“EQ/FFE 없이 5-tap 채널을 통과시키면, PAM4든 CoPBit-M8이든 BER상으로 이득을 논할 단계가 아니다”
를 보여주는 raw baseline 이라고 보는 게 맞음.
	2.	PAM4 vs CoPBit-M8 관계
	•	비트당 에너지(Eb) 기준으로 공정 비교를 했음에도,
8-PSK(M=8, 3bit/sym) 는 항상 PAM4(2bit/sym) 보다 BER이 더 나쁘게 나옴.
	•	이유:
	•	8-PSK는 위상 도메인에서 M=8 등간격 → 심볼 간각이 45°라서
동일 Eb/N0 기준에서 AWGN/ISI에 더 취약.
	•	5-tap 채널로 인한 위상/진폭 smear가 복소 평면 전체로 퍼지기 때문에
단순 최근접 PSK 디코더로는 회복이 어렵다.
	•	하지만, CoPBit-M8은 심볼당 3bit라서,
“동일 BER 타겟에서 필요한 Eb/N0” vs “비트레이트/대역폭/전력”을 묶어서 비교해야 진짜 효율 비교가 가능.
	•	지금 v0.1은 “디지털 물리층 앞단에서, EQ 없이 raw로 넣었을 때 버틴다/못 버틴다” 수준의 기초 실험.
	3.	Q9/Q10과의 연결
	•	Q9/Q10 AWGN-only에서는:
	•	M=2,4,8,16 PSK가 깨끗한 AWGN 환경에서의 이상적인 BER 곡선을 보여줌.
	•	Q12는 여기에 현실적인 5-tap 채널 a/b/c를 얹었을 때,
	•	EQ=0인 상태에서 얼마나 빨리 “채널 limit”에 도달하는지 시각화한 셈.
	•	메시지:
“채널 a/b/c 환경에서는, EQ/FFE/위상 보정 없이 CoPBit를 넣어도
1e-2 수준 BER까지는 절대 못 간다 → equalizer + CoPBit 특유의 위상 보정 구조가 필수”
