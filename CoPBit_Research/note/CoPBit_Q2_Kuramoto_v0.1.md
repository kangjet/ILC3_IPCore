## 1. Q2 목표

- Q1에서 정의한 **16포인트 3D 위성 (4bit/심볼)** 을
  - Kuramoto 스타일 위상 커플링 모델에 올려보고,
  - “같은 클러스터는 잘 뭉치고, 다른 클러스터는 상대적으로 분리되는지” 1차 감을 잡는 것.
- 장기적으로는:
  - CoPBit 1024-lane에서의 **암호/보안/PPU primitive**로 쓰기 위해,
  - 1-lane Kuramoto 동작이 어떤 특성을 가지는지 시각적으로 확인하는 단계.

## 2. 기본 설정 (Q1 결과 재정리)

- 4bit/심볼 → 16포인트 고정.
- 좌표:
  - r = 1 (정규화)
  - θ_k = 2π·k/16,  k = 0..15
  - c = ⌊k/4⌋,  c ∈ {0,1,2,3}
  - φ_c = c·φ_step,  φ_step = π/16 (v0.1 기준값)
- 비트 매핑:
  - (b3 b2) = 클러스터 인덱스 c
  - (b1 b0) = 클러스터 내부 인덱스 i
  - k = 4c + i

여기서 Q2에서는 우선 **θ_k만 Kuramoto 위상 변수**로 사용하고,  
φ_c는 “클러스터 ID”로만 사용(커플링 강도 결정에 쓰는 메타 정보)한다.

## 3. Kuramoto 모델 v0.1 정의

### 3.1 연속형 기본식

- i번째 오실레이터(심볼 포인트)의 위상을 θ_i(t)라 할 때,
  
  \[
    \frac{d\theta_i}{dt}
    = \omega_i
      + \frac{1}{N} \sum_{j=0}^{N-1} K_{ij} \sin(\theta_j - \theta_i)
  \]

- 여기서:
  - N = 16 (Q2 v0.1에서는 16포인트를 그대로 사용)
  - ω_i: 각 오실레이터의 자연 주파수 (v0.1에서는 모두 동일 ω로 두거나, 약간 랜덤하게 줄 수 있음)
  - K_{ij}: 커플링 강도 행렬
    - **같은 클러스터(c_i = c_j)**: K_intra (큰 값)
    - **다른 클러스터(c_i ≠ c_j)**: K_inter (작은 값)

### 3.2 클러스터 기반 커플링 행렬

- i번째 포인트의 클러스터 c_i = ⌊i/4⌋
- K_{ij} v0.1 정의:

  \[
    K_{ij} =
    \begin{cases}
      K_{\text{intra}}, & c_i = c_j,\ i \ne j \\
      K_{\text{inter}}, & c_i \ne c_j \\
      0, & i = j
    \end{cases}
  \]

- 예시 파라미터:
  - K_intra = 1.0
  - K_inter = 0.1
  - ω_i = 0 (자연 주파수는 일단 0으로 두고, 순수 커플링 효과만 봄)

## 4. 이산 시간 시뮬레이션 v0.1

연속식을 간단히 오일러 방식으로 이산화:

- 시간 스텝: Δt
- T_total 동안 T_step = T_total / Δt 번 반복

업데이트식:

\[
  \theta_i(t + \Delta t)
  = \theta_i(t)
    + \Delta t \left[
      \omega_i
      + \frac{1}{N} \sum_{j=0}^{N-1} K_{ij} \sin(\theta_j(t) - \theta_i(t))
    \right]
\]

시뮬레이션 전략:

1. 초기 위상 θ_i(0)를 Q1에서 정의한 θ_k로 설정:
   - θ_i(0) = 2π·i/16
2. 각 타임스텝마다 θ_i(t)를 업데이트.
3. 최종적으로:
   - 클러스터별로 θ_i(t)가 얼마나 근접하게 모이는지,
   - 다른 클러스터와의 위상 차이는 어느 정도 유지되는지 확인.

## 5. 실험 시나리오 (Q2 v0.1)

### 실험 1 – 같은 클러스터 강하게, 다른 클러스터 약하게

- 파라미터:
  - N = 16
  - K_intra = 1.0
  - K_inter = 0.1
  - ω_i = 0 (all i)
  - Δt = 0.05
  - T_total = 50.0 (→ 1000 스텝)

- 관찰 포인트:
  - 클러스터 별 평균 위상:
    \[
      \bar{\theta}_c(t) = \frac{1}{4}\sum_{i: c_i = c} \theta_i(t)
    \]
  - 같은 클러스터 안의 위상 차이가 시간이 지날수록 줄어드는지 확인.
  - 다른 클러스터 간 위상 거리(예: |θ̄_0 - θ̄_1| 등)가 어느 정도 유지되는지 확인.

### 실험 2 – K_inter를 키워서 “전체 동기화” 경향 보기

- K_intra = 1.0 (고정), K_inter를 0.1 → 0.5 → 1.0 으로 변경.
- K_inter가 커질수록:
  - 모든 16포인트가 하나의 큰 클러스터로 수렴하는지,
  - 아니면 여전히 클러스터 구조가 남는지 관찰.
