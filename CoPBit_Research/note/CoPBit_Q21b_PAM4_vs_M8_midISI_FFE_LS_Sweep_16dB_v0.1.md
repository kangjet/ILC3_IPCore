# CoPBit Q21b – PAM4 vs M8 mid-ISI (Channel-b) + FFE(LS) 파라미터 스윕 @ Eb/N0=16 dB v0.1

## 1. 실험 목적

- ILC-4 CoPBit 환경에서 **Channel-b mid-ISI + AWGN** 조건에서  
  PAM4 vs M8 비교 시 사용할 **FFE-only LS 기준선(baseline)** 을 확정하기 위함.
- FFE 길이(`ffe_len`)와 학습 구간 비율(`train_frac`)을 바꾸면서  
  **Eb/N0 = 16 dB**에서의 BER 변화를 측정.
- 목표:
  - PAM4 / M8 모두에서 **안정적이고 평탄한 BER** 구간을 확인.
  - 이후 CoPBit 메모리/버스 테스트(Q21 이후 단계)의 **공통 FFE 설정**을 결정.

---

## 2. 공통 시뮬레이션 환경

- 채널: `Channel-b` 5-tap mid-ISI, 심볼레이트 등간격
  - 정규화 계수:  
    \[
    h_\text{midISI} = [0.04075696, 0.40756957, 0.81513915, 0.40756957, 0.04075696]
    \]
- 노이즈: AWGN, Eb/N0 = **16 dB** (Q21b CSV는 16 dB 고정 기준)
- 변조
  - PAM4: 2 bit/sym, 심볼 레벨 4단
  - M8: 3 bit/sym, 8-PSK (unit circle)
- Equalizer
  - 구조: **단일 FFE** (DFE 없음), LS(Least Squares)로 계수 추정
  - 길이: `ffe_len ∈ {7, 9, 11, 13}`
  - 학습 구간: `train_frac ∈ {0.3, 0.5, 0.8, 1.0}`
  - 학습은 **송신 심볼을 그대로 사용한 트레이닝 모드(DD 아님)** 로 가정
- 기타
  - 심볼 수: `n_sym = 200000`
  - 랜덤 시드: `seed = 1`
  - 동일한 FFE 구조 / 채널 / 노이즈 아래에서 PAM4, M8을 각각 독립 테스트

### 3.2 Baseline 선택 기준

Q21 이후 실험에서 **하나의 FFE 설정**을 공통으로 쓰기 위해, 아래 조건들을 고려했다.

1. **PAM4 / M8 모두에서 안정적인 성능**
   - 모든 `(ffe_len, train_frac)` 조합에서 BER이 비슷한 수준으로 유지.
   - 특별히 “한 지점만 급격히 좋아지는” 구간이 없고, **균일하게 평탄한 plateau**.

2. **중간 길이의 필터 + 중간 학습 비율**
   - FFE 길이 11은:
     - 7 / 9 탭보다 **조금 더 완만하게 채널을 보상**하는 중간 설정.
     - 13 탭 대비 복잡도 / 오버피팅 리스크가 덜함.
   - train_frac 0.5는:
     - 전체 심볼의 절반만 학습에 쓰고, 나머지 절반은 검증 구간으로 남길 수 있어  
       **추후 PhaseLock_std나 Kuramoto 결합 시에도 일관된 구조**를 유지하기 좋음.

3. **기존 Q20c/Q21a 흐름과의 정합성**
   - 이미 Q20c(PAM4) / Q21a(PAM4 vs M8)에서 **ffe_len=11, train_frac=0.5** 환경을  
     중심으로 실험을 진행해왔기 때문에,  
     Q21b 결과도 이 설정이 plateau 안에 들어가는지 검증하는 성격.
   - Q21b 결과에서 이 조합은 여전히 plateau 내에 존재 →  
     **앞뒤 실험 흐름과 자연스럽게 이어지는 선택**.

### 3.3 최종 Baseline 확정

- 앞으로의 **mid-ISI + FFE-only, Eb/N0=16 dB 기준 메모리/버스 CoPBit 실험**에서  
  기본 PAM4/M8 baseline은 다음으로 확정:

> **Baseline FFE 설정 (Q21 계열 공통)**
> - ffe_len = **11**
> - train_frac = **0.5**
> - eq_mode = **LS (고정 계수)**
> - 채널: Channel-b mid-ISI
> - AWGN: Eb/N0 = 16 dB 기준

- 이때 대표적인 BER 레벨:
  - PAM4 FFE: **BER ≈ 0.213**
  - M8 FFE: **BER ≈ 0.162**
  - → M8이 같은 조건에서 PAM4 대비 **약 0.05 절대 BER 이득**을 보여주며,  
    mid-ISI + FFE-only 환경에서도 **M8 구성의 잠재력이 확인됨.**

## 4. 요약 메모

- Q21b는 “**FFE 파라미터에 따른 큰 최적점이 있는가?**”를 보는 실험이었고,
  - 실제로는 **넓은 plateau 영역**이라는 것이 확인되었음.
- 따라서, 이후 CoPBit 메모리/버스 시나리오에서는
  - FFE를 “미세 튜닝 대상”이 아니라,  
    **고정 baseline 블록**으로 보고,
  - 그 위에 **PhaseLock_std, p_ref 배치, lane 수(N_ref, N_data)** 같은  
    CoPBit 고유 설계 변수에 집중하는 것이 합리적.
- 결론:
  - **Q21b 결과로 FFE-only baseline은 확정**되었고,  
    다음 스텝은 이 baseline 위에서 **위상·멀티레인 효과(CoPBit 설계 변수)**를  
    어떻게 쌓아가는지가 핵심 과제로 남아 있다.
