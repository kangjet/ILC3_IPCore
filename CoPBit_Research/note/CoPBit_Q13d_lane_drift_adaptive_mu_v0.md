# CoPBit Q13d – xN lanes M8 + Channel-b + FFE + adaptive + limited-step Kuramoto (Eb/N0 basis) v0.1

## 1. 실험 목적

- 강 ISI 채널 b = `[0.05, 0.5, 1.0, 0.5, 0.05]` 에서
  - CoPBit-M8(8-PSK, 3 bit/sym) + 채널 + AWGN + FFE(5tap)
  - xN lanes + 글로벌 위상 드리프트 + Kuramoto 위상 락
- 조건:
  - lane 수 \(L \in \{4, 16, 64, 256\}\)
  - drift_std_deg \(\in \{0.5°, 1.0°, 2.0°, 3.0°\}\)
  - Eb/N0 \(\in \{10, 12, 14\}\) dB
- 비교 대상:
  - **BER_M8_base**: Kuramoto OFF, 각 레인 독립 8-PSK 디코딩
  - **BER_M8_kura(adapt)**: adaptive + limited-step Kuramoto 적용 후 BER

Q13b(기본 Kuramoto) / Q13c(φ step limit)와 비교해서  
**adaptive-step (|err_phasor| 가중)** 이 실제로 drift 허용 범위를 얼마나 바꾸는지 보는 것이 목적.

---

## 2. 파라미터 요약

- 공통 설정
  - `n_sym = 100000` (lane 당 심볼 수)
  - `Eb/N0_list = [10, 12, 14]` dB
  - `lanes_list = [4, 16, 64, 256]`
  - `drift_list = [0.5, 1.0, 2.0, 3.0]` deg (글로벌 위상 random walk 표준편차)
  - 채널 b: `[0.05, 0.5, 1.0, 0.5, 0.05]`
- FFE
  - 심볼 레이트 FFE, LS 설계
  - `ffe_len = 5`, `train_frac = 0.2`
  - 채널 b + 8-PSK 기준으로 한 번 설계하여 모든 조합에 공통 사용
- Kuramoto (Q13d)
  - base 스텝: `mu_phase = 0.1`
  - step limit: `phi_max_deg = 10°`
  - adaptive-step:
    - `err_phasor = mean(z_n * conj(s_hat))`
    - `w = |err_phasor| ∈ [0, 1]` (phasor coherence)
    - `delta = mu_phase * w * err`, 이후 ±φ_max_rad로 clip
    - `phi_est ← phi_est + delta`
- 변조 / AWGN
  - M8 (8-PSK), unit circle, 3 bit/symbol
  - Eb/N0 기반 bit-fair AWGN
  - 모든 lane에 같은 Eb/N0 적용

4. Q13b/Q13c와 비교한 패턴 해석

4.1 drift_std_deg = 0.5° (실질 운영 영역)
	•	Q13b/Q13c 대비 큰 차이 없음:
	•	예: (16 lanes, 12 dB)
	•	Q13b/13c: BER_kura ≈ 1.359e-01
	•	Q13d:     BER_kura(adapt) ≈ 1.357e-01
	•	예: (16 lanes, 14 dB)
	•	Q13b/13c: ≈ 9.285e-02
	•	Q13d:     ≈ 9.289e-02
	•	의미:
	•	이미 Kuramoto가 잘 락 잡는 구간에서는 |err_phasor| ≈ 1에 가까워서
	•	adaptive-step이 사실상 고정 μ와 거의 동일하게 동작.
	•	lane↑ + Eb/N0↑ 조합에서 BER은 여전히 1e-1~1e-2 수준까지 잘 내려감.
	•	예외:
	•	(4 lanes, 10 dB) 등 일부 저 Eb/N0 + 소수 lane 조합에서는
	•	base보다 BER 나빠지거나 들쭉날쭉한 구간이 존재 (락 실패/불안정 영역).

4.2 drift_std_deg = 1.0° (경계 영역)
	•	4 lanes:
	•	14 dB에서 BER_base ≈ 0.5475 → kura(adapt) ≈ 0.3470 로 한 번 튀는 개선 존재.
	•	다만 다른 Eb/N0 / lane 조합까지 확장되는 “안전 영역”이라기보다는
샘플링/난수에 따라 왔다 갔다 하는 경계 느낌.
	•	16/64/256 lanes:
	•	Q13b/13c와 비슷한 스케일:
	•	어떤 조합에서는 약간 더 좋고, 어떤 조합에서는 약간 더 나쁘거나 비슷.
	•	정성적으론
	•	drift=1°에서 일부 고 Eb/N0 + 많은 lane 조합에서만 락이 의미 있게 작동.
	•	결론:
	•	drift 1° 영역은 여전히 “조건부 운영 가능 영역”
	•	adaptive μ가 Q13c 대비 큰 마진 확장까지는 못 보여줌.
	•	그래도 φ_max와 함께 쓰면 폭주를 어느 정도 제어하는 효과는 유지.

4.3 drift_std_deg = 2° / 3° (한계 영역)
	•	drift ≥ 2°:
	•	대부분 조합에서 BER_kura(adapt) ≈ BER_base ≈ 0.48~0.54 근처.
	•	곳곳에서 미세한 +/- 변화가 있지만
	•	구조적으로 락이 깨져서 **랜덤 디코딩 수준(≈0.5)**에 가까움.
	•	요약:
	•	drift_std_deg가 2° 이상으로 커질 경우
	•	Q13b/13c와 마찬가지로 adaptive-step도 운영 영역 확장에는 실패.
	•	이 구간은 사실상 CoPBit 멀티레인 Kuramoto 위상 락의 한계 영역으로 보는 게 타당.

5. 현재까지의 결론 (Q13 계열 전체 관점)
	1.	운영 가능 영역(실질 CoPBit phase-lock zone)
	•	drift_std_deg ≲ 0.5°
	•	n_lanes ≥ 16, Eb/N0 ≥ 12 dB 수준에서
	•	M8 base 대비 Kuramoto (기본/limited/adaptive) 모두
BER이 0.13~0.09 정도까지 내려가며,
	•	강 ISI 채널 b에서도 CoPBit 위상 락의 실효성을 확인.
	•	adaptive-step(Q13d)은 이 영역에서 Q13b/13c와 거의 동일한 성능.
	2.	경계 영역 (borderline zone)
	•	drift_std_deg ≈ 1°
	•	lane 수와 Eb/N0에 따라
	•	어떤 조합에서는 분명 BER 개선이 보이고,
	•	어떤 조합에서는 거의 이득이 없거나, 오히려 애매해지는 구간 존재.
	•	adaptive-step은
	•	락되는 케이스에서 급격한 폭주를 조금 더 제어해 줄 가능성이 있지만,
	•	수치상으로 크게 안정 영역을 넓혀주지는 못함.
	3.	한계 영역 (no-lock zone)
	•	drift_std_deg ≥ 2°
	•	lane↑, Eb/N0↑, adaptive-step, φ_max 제한을 모두 써도
	•	BER이 거의 0.5 근처에서 머물러 락 실패.
	•	여기서는 Kuramoto만으로는 부족하고,
	•	추가적인 PLL/DLL, pilot-based tracking, phase quantization 구조 변경 등이 필요.
	4.	요약 메시지
	•	Q12c(FFE sweet spot) + Q13 + Q13b/c/d를 묶어서 보면,
	•	“강 ISI + 멀티레인 CoPBit에서, drift_std_deg가 0.5° 이하로 관리되는 환경”
이 CoPBit phase-lock 아키텍처의 1차 타깃 운영 영역.
	•	Q13d의 adaptive-step은
	•	이미 락이 잘 되는 영역에서는 Q13c와 비슷한 성능,
	•	drift가 커지는 경계/한계 영역에서는 부분적 완화 수준.
    6. 후속 아이디어
	•	Q13d 확장:
	•	φ_max_deg 스윕 (예: 3°, 5°, 10°)으로
“보수적인 step-limit vs 수렴 속도” 트레이드오프 맵 확보.
	•	lane 수를 512, 1024까지 늘린 coarse 테스트로
	•	“극단적 멀티레인”에서 Kuramoto가 어디까지 버티는지 확인.
	•	시스템 레벨 연결:
	•	실제 CoPBit IO-bus에서 허용 가능한
	•	**위상 wander 스펙(drift_std_deg)**를 역산해서,
	•	패키지/클럭/온도 조건과 연결한 “시스템 요구사항” 초안 작성 가능.
	•	향후:
	•	PAM4_FFE vs CoPBit_M8_Kuramoto(Q13 계열)를 한 그림에 올려서
	•	“PAM4 동일 채널에서 CoPBit가 언제 이득을 줄 수 있는가”를
SNR–drift–lane 3축 중 2D 슬라이스로 시각화.

### X.Y Drift 1°에서 Eb/N0 스윕 (μ_phase = 0.10, φ_max = 10°, n_sym = 1e6)

**실험 조건**

- 스크립트: `copbit_q13d_lane_drift_adaptive_mu_v0.py`
- n_sym = 1,000,000
- Eb/N0_list = [18, 19, 20, 21, 22, 23] dB
- lanes_list = "64"
- drift_list = "1.0"
- channel = b ([0.05, 0.5, 1.0, 0.5, 0.05])
- ffe_len = 7, train_frac = 0.2
- μ_phase = 0.10
- φ_max_deg = 10°

**결과 요약 (drift_std_deg = 1.00°)**

| Eb/N0(dB) | BER_M8_base | BER_M8_kura(adapt) |
|----------:|------------:|--------------------:|
| 18        | 5.133e-01   | 2.890e-02           |
| 19        | 5.058e-01   | 1.897e-02           |
| 20        | 4.888e-01   | 1.213e-02           |
| 21        | 5.076e-01   | 7.523e-03           |
| 22        | 4.955e-01   | 4.563e-03           |
| 23        | 4.647e-01   | 2.757e-03           |

**해석**

- base BER는 0.46~0.51 수준으로 **랜덤 추측(0.5)** 에 가깝다.
- Kuramoto + FFE 구조는 drift_std=1°임에도 불구하고:
  - 18 dB에서 이미 **BER ≈ 2.9e-2 (3e-2 threshold 이내)**,
  - 19~20 dB에서 **BER ≈ (1.9~1.2)e-2**,  
  - 21 dB 이상에서는 **1e-2를 명확히 하회 (7.5e-3 이하)**.
- n_sym = 1e6 기준이므로, 짧은 패턴 우연 효과가 아니라 **장기 수렴 기준의 안정적인 위상락**으로 볼 수 있다.

**스펙 관점 요약**

- drift_std = 1°, L=64, FFE=7, μ_phase=0.10, φ_max=10° 조건에서:
  - **Eb/N0 ≈ 20.5 dB 이상**이면 pre-FEC BER ≤ 1e-2 수준 달성 가능.
  - **Eb/N0 ≥ 22 dB**에서는 BER ≈ 4.6e-3 수준으로 추가 마진 확보.
- Q13e에서 확인한 drift_std=2° 결과와 비교하면,
  - σ_drift ≲ 1° 구간은 현 구조에서 **“실제 운영 가능한 위상락 사양”**,
  - σ_drift ≈ 2°는 **동일 구조 기준 “out-of-spec drift”**로 보는 것이 합리적이다.
