## 1. 목표

- μ_phase, φ_max_deg 튜닝으로 drift_std=2° 조건에서 BER을 1e-2~3e-2 영역까지 개선 가능 여부 평가.
- 조건 고정: Channel-b, M8(8-PSK), FFE len=7, train_frac=0.2, lanes=64.

## 3. μ_phase / φ_max 튜닝 결과 (drift_std = 2°)

### 3.1 μ_phase 스윕 (phi_max_deg = 10° 고정, drift_std=2°, L=64, FFE=7)

**실험 조건**

- n_sym = 500,000
- Eb/N0_list = [20, 22] dB
- lanes_list = "64"
- drift_list = "2.0"
- ffe_len = 7, train_frac = 0.2
- phi_max_deg = 10°
- μ_phase ∈ {0.02, 0.05, 0.10(baseline), 0.20}

**결과 요약**

| μ_phase | Eb/N0(dB) | BER_M8_base | BER_M8_kura(adapt) |
|--------:|----------:|------------:|--------------------:|
| 0.10    | 20        | 4.951e-01   | **5.433e-01**       |
|         | 22        | 4.891e-01   | **4.990e-01**       |
| 0.02    | 20        | 4.951e-01   | 4.838e-01           |
|         | 22        | 4.891e-01   | 5.053e-01           |
| 0.05    | 20        | 4.951e-01   | 5.062e-01           |
|         | 22        | 4.891e-01   | 4.950e-01           |
| 0.20    | 20        | 4.951e-01   | **1.288e-01**       |
|         | 22        | 4.891e-01   | **6.604e-03**       |

**해석**

- μ_phase ≤ 0.10 구간에서는  
  - BER_M8_kura ≈ 0.48~0.54 수준으로 **거의 “랜덤 추측(0.5)”** 상태.  
  - drift_std=2°에서 Kuramoto 위상락이 사실상 붕괴한 상태로 볼 수 있음.
- μ_phase = 0.20에서 큰 변화 발생:
  - 22 dB: **BER ≈ 6.6e-3** → Q13e 목표(1e-2 ~ 3e-2)보다 낮은 수준까지 회복.  
    → drift_std=2°에서도 **충분한 SNR(≈22 dB)** 가 있으면 위상락이 다시 잡힌다는 것을 의미.
  - 20 dB: BER ≈ 1.3e-1 → 여전히 허용치보다 높음.  
    → 동일 drift=2° 조건에서 **SNR이 낮으면 강한 μ만으로는 부족**, 추가적인 여유(dB) or 다른 구조 개선 필요.

> 정리하면, **drift_std=2°에서 “위상락 가능한 영역”이 22 dB 근처에 새로 열렸다.**  
> 20 dB에서는 μ 튜닝만으로는 아직 1e-2 영역에 도달하지 못함.

**해석**

- μ_phase = 0.05에서 φ_max_deg를 5°→10°→20°로 크게 바꿔도  
  - BER_M8_kura가 **항상 ≈0.50 근처에서 거의 변하지 않음.**
- 즉 **“스텝 상한(phi_max)”이 문제라기보다는, 기본 μ_phase가 너무 작아서**
  - err_phasor에 비해 위상 업데이트가 거의 진행되지 못하고 있는 상태.
- 결론적으로, drift_std=2° 영역에서는  
  - 작은 μ에서 φ_max_deg 튜닝은 효과가 거의 없고,  
  - **먼저 μ_phase를 충분히 키워서 “락이 걸릴 수 있는 영역”까지 끌어올린 뒤**  
    세부 조정용으로 φ_max_deg를 쓰는 게 맞다는 것을 확인.

### 3.3 Q13e 1차 결론 (drift_std = 2°)

1. **드리프트 2°에서의 위상락 조건**
   - Channel-b, M8, FFE=7, L=64, train_frac=0.2에서
   - μ_phase = 0.20, φ_max_deg = 10°일 때  
     - 22 dB: BER ≈ 6.6e-3 → **drift_std=2°에서도 실질적인 위상락 달성.**
   - ⇒ CoPBit 위상락 사양에  
     > “σ_drift ≈ 2° @ 22 dB에서 BER ≈ 1e-2 이하 달성 가능”  
     같은 문장을 넣을 수 있는 근거 데이터가 확보됨.

2. **SNR 의존성**
   - 동일 설정에서 20 dB에서는 BER ≈ 1.3e-1 수준.  
   - drift_std=2°를 유지하면서 1e-2 이하 BER을 원한다면  
     - SNR 측면에서 **약 +2 dB 이상의 여유가 필요**하다는 의미.

3. **튜닝 전략 관점**
   - drift가 작을 때(≤1°): μ_phase ≈ 0.1, φ_max_deg=10°로 충분.  
   - drift가 커질 때(≈2°):  
     - **먼저 μ_phase를 키워서(예: 0.2)** 빠른 트래킹을 확보한 뒤,  
     - 그 위에 φ_max_deg나 lane 수(L) 스케일링 등으로 안정성을 다듬는 게 합리적인 설계 방향.

**결과 요약 (drift_std_deg = 2.00°)**

| Eb/N0(dB) | BER_M8_base | BER_M8_kura(adapt) |
|----------:|------------:|--------------------:|
| 18        | 5.119e-01   | 5.551e-01           |
| 19        | 5.082e-01   | 4.865e-01           |
| 20        | 4.913e-01   | 4.088e-01           |
| 21        | 5.039e-01   | 2.702e-01           |
| 22        | 4.936e-01   | 5.212e-01           |
| 23        | 4.849e-01   | 2.807e-01           |

**해석**

- 전체적으로 **BER_M8_kura가 0.27 ~ 0.56 사이**에 머무르며,  
  - 목표 영역인 **1e-2 ~ 3e-2보다 훨씬 높은 수준**에 머무름.
- SNR별 특징:
  - 18 dB: base ≈ 0.51 → kura ≈ 0.55 (오히려 악화, 완전 랜덤 추측 이상).
  - 19 dB: base ≈ 0.51 → kura ≈ 0.49 (미미한 개선, 사실상 랜덤과 유사).
  - 20 dB: base ≈ 0.49 → kura ≈ 0.41 (일부 개선이 있으나 여전히 4e-1 수준).
  - 21 dB: base ≈ 0.50 → kura ≈ 0.27 (가장 좋은 포인트이지만 여전히 1e-1 대).
  - 22 dB: base ≈ 0.49 → kura ≈ 0.52 (위상락 붕괴, 랜덤 추측 수준으로 재전락).
  - 23 dB: base ≈ 0.48 → kura ≈ 0.28 (다시 어느 정도 개선되지만 2.8e-1 수준).
- n_sym을 5e5 → 1e6으로 늘리면서,  
  - **이전 500k 심볼에서 관측된 “우연에 가까운 저 BER(예: 22 dB에서 ≈ 6.6e-3)”이 장기적으로 유지되지 않음**이 드러남.
  - 즉, drift_std=2°에서 μ_phase=0.20, φ_max_deg=10° 설정은  
    - 일부 구간에서 **부분적으로 메타-안정(meta-stable)** 한 락 구간이 있을 수 있으나,  
    - 긴 심볼 길이에서는 다시 위상락이 풀리거나 다른 attractor로 이동하는 **불안정한 상태**에 가깝다고 보는 것이 타당.

**요약 결론 (Drift 2°, L=64, FFE=7, μ=0.20, φ_max=10°)**

- 이 설정에서 **Eb/N0 18~23 dB 범위 내에는 “안정적인 1e-2 BER threshold”가 존재하지 않는다.**
- Kuramoto 기반 위상락은 drift_std=2°에서
  - **장기(n_sym=1e6) 기준으로는 안정적인 동기 상태를 유지하지 못하고,**
  - SNR과 상관없이 0.27~0.56 범위의 높은 BER에 머무는 구간이 넓게 존재.
- 따라서 Q13e 관점에서
  - drift_std=2°는 **현재 1차 Kuramoto + FFE 구조에서 “실질적으로 허용 가능한 연산/통신 모드”로 보기 어렵다.**
  - 실용 스펙 정의 시에는  
    > “본 구조에서는 σ_drift ≲ 1° 수준에서만 1e-2 이하 BER을 목표로 한다”  
    와 같이, drift=2°는 현 구조 기준 **“spec 밖(out-of-spec)” 영역**으로 두는 것이 합리적이다.
