# CoPBit Q3 – 4bit 위상 디코딩 BER 노트 v0.1

## 1. 실험 개요

- 스크립트: `CoPBit_Research/python/copbit_q3_phase_decode_demo_v0.py`
- 목적:
  - Q1에서 정의한 **16포인트(4bit) 위상 위성**에 대해,
  - **Kuramoto 동기화 없이** 순수 위상 AWGN + 최근접 위상 디코더만 사용했을 때의 BER 베이스라인 측정.
- 설정:
  - 심볼 수: `n_sym = 10,000`
  - 위상 노이즈: 평균 0, 표준편차 σ (deg 단위)
  - 시드: `seed = 1`
  - 맵핑:
    - `k = 0..15` → `theta = 2πk/16`
    - `(c, p)` (2bit + 2bit) ↔ 4bit 코드 `B` (0..15)
  - 디코딩:
    - 수신 위상 `theta_rx`에 대해, 16포인트 중 원형 거리 |wrap(θ_rx−θ_k)|가 최소인 `k_hat` 선택
    - `B_rx = k_hat` 로 복원
- 출력:
  - Symbol accuracy = 올바르게 판독된 심볼 비율
  - Bit BER = 전체 전송 비트 수 대비 비트 에러 비율 (4bit/심볼 기준)

## 3. 해석 및 코멘트

1. **저노이즈 구간 (σ ≈ 3°)**
   - Bit BER ≈ 1e-4 수준으로 매우 낮음.
   - 단순 위상 AWGN + 최근접 위상 디코더만으로도, 4bit 위상 심볼이 충분히 안정적인 영역.

2. **중간 노이즈 구간 (σ ≈ 4~5°)**
   - 4°: BER ≈ 2.2×10⁻³ → 일반적인 FEC와 조합하면 무난히 커버 가능한 영역.
   - 5°: BER ≈ 1.2×10⁻² → pre-FEC 기준으로는 다소 높은 쪽이지만,
     - 강한 FEC(예: LDPC/BCH)와 조합하면 여전히 유효할 수 있는 수준.
     - Kuramoto 기반 동기화/보정이 들어가면, 같은 σ에서 BER 개선 여지를 기대할 수 있음.

3. **고노이즈 구간 (σ ≥ 6°)**
   - 6°: BER ≈ 2.7×10⁻²
   - 8°: BER ≈ 7.4×10⁻²
   - 단순 위상 AWGN + 최근접 위상 디코더만으로는 점점 한계에 가깝고,
     - Kuramoto 동기화, 위상 트래킹, Decision Feedback 등의 보조 구조가 필요해지는 영역.

---

## 4. Q4 (Kuramoto-aided 디코딩)와의 연결 포인트

- Q3-2 실험은 **Kuramoto 없이** “순수 위상 채널 + 최근접 디코더”의 베이스라인.
- Q4에서는 다음과 같은 확장 실험을 계획:
  1. 동일한 위상 노이즈 σ(3~8°)에서,
  2. Kuramoto 위상 동기화(또는 위상 군집화) 알고리즘을 추가한 뒤,
  3. BER 곡선을 Q3-2 베이스라인과 비교.
- 기대 효과:
  - 같은 σ에서 BER 곡선이 **왼쪽으로 이동**(= 더 큰 노이즈에서도 같은 BER 유지)하면,
    - “Kuramoto-aided CoPBit 위상 디코딩
    - 이는 추후 특허/논문에서:
    - “기존 위상 변조 + 단순 디코더” 대비,
    - “Kuramoto 기반 집단 위상 동기화 + 디코딩” 구조의 우위를 설명하는 데 활용 가능.

# CoPBit Q3 – 4bit 위상 디코딩 BER 베이스라인 (v0.1)

## 1. 실험 개요

- 목적:
  - CoPBit 1-lane 4bit 위상 스킴(16포인트 위상 위성)에 대해  
    **Kuramoto 동기화 없이** 순수 위상 AWGN + 최근접 위상 디코더만 사용했을 때의  
    **기본 BER 곡선(베이스라인)** 을 얻는다.
- 맵핑:
  - k = 0..15 → θ_k = 2π·k/16 (16포인트 균일 위상)
- 채널/디코더 모델:
  - 송신 위상: θ_tx = θ_table[k_tx]
  - 위상 노이즈: θ_rx = wrap(θ_tx + N(0, σ_deg))  (deg → rad 변환 후 적용)
  - 디코딩: θ_rx에 대해 |wrap(θ_rx − θ_k)|가 최소인 k_hat 선택 (최근접 위상 디코더)
- 출력 지표:
  - Symbol Accuracy = P(k_hat = k_tx)
  - Bit BER = 4bit 심볼 기준 비트 에러율

실험 스크립트:

- `CoPBit_Research/python/copbit_q3_phase_decode_sweep_v0.py`  
- 기본 실행:
  - `python copbit_q3_phase_decode_sweep_v0.py`
- 심볼 수 확장:
  - `python copbit_q3_phase_decode_sweep_v0.py --n_sym 50000 --sigma_list 3,4,5,6,8`

### Q7: 2bit + Guard 모드 (폐기된 아이디어)

- 16-PSK(16포인트, 22.5° 간격) 위상 배치는 그대로 유지하면서,
  상위 2bit만 payload, 클러스터 축(c)을 guard로 랜덤 사용.
- 동일 Es/N0 조건에서 BER 비교 결과:
  - 4bit CoPBit4 대비 전 SNR 영역에서 BER 이득 없음.
  - 고 SNR에서도 2bit+guard 모드가 4bit보다 나쁘거나 비슷한 수준.
- 결론: guard 축을 이 방식으로 쓰는 것은 **에러 보호에 기여하지 못함.**
  ⇒ CoPBit 본라인 설계에서 제외(폐기).
